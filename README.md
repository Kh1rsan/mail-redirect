# Пересылка писем Mail.ru на другой адрес

Скрипт проверяет `INBOX` ящика Mail.ru по IMAP и пересылает текст новых писем на указанный адрес через SMTP, только если отправитель — `noreply@rockstargames.com`, а тема в точности равна `Ваш проверочный код Rockstar Games`. HTML-тело преобразуется в текст; вложения не пересылаются. Остальные письма пропускаются.

## Настройка

1. Установите Python 3.10 или новее.
2. В Mail.ru включите IMAP и создайте пароль для внешнего приложения с доступом к почте. Для входящих писем используются `imap.mail.ru:993` с SSL/TLS.
3. Заполните `.env` в папке проекта. Скрипт загружает его автоматически при старте. Переменные, уже заданные в окружении Windows, имеют приоритет над значениями из `.env`.

Пример содержимого `.env`:

```dotenv
MAIL_EMAIL=source@mail.ru
MAIL_APP_PASSWORD=пароль_внешнего_приложения
FORWARD_TO=recipient@example.com

# Необязательно; по умолчанию используются настройки SMTP Mail.ru.
# SMTP_HOST=smtp.mail.ru
# SMTP_PORT=465
# SMTP_SECURITY=ssl
# SMTP_USER=source@mail.ru
# SMTP_PASSWORD=пароль_отправителя
# SMTP_FROM=source@mail.ru
# POLL_SECONDS=60
```

Для отправки через другой почтовый сервис укажите его SMTP-сервер и учётные данные. Поддерживаются `ssl` и `starttls`.

Запуск:

```powershell
python .\mail_forwarder.py
```

## Поведение

Проверка выполняется раз в минуту. При первом запуске уже существующие письма пропускаются. Обработанный IMAP UID хранится в `mail_forwarder_state.json`; письма остаются в почтовом ящике и сохраняют статус прочтения. Если отправка не удалась, письмо будет повторно обработано при следующей проверке.
